# Punters Data Vision

## Purpose

Punters Data aims to provide users with data-driven probability predictions and true odds for gambling markets across racing and sports.

The platform will analyse historical performance, current conditions, market prices and statistical trends to identify value opportunities.

## True Odds Calculation
The system will compare:
- Market odds
- Historical performance
- Statistical probability
- Predicted outcome

Output:
- Probability %
- True odds
- Value rating

Example:

Horse A:
Market odds: $5.00
Calculated probability: 30%

True odds:
1 / 0.30 = $3.33

Value:
YES
