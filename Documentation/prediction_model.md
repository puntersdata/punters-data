# Punters Data - Prediction Model

## Purpose

The Punters Data prediction model analyses historical performance, conditions, statistics and market information to calculate:

- Probability of an outcome occurring
- True odds value
- Difference between model odds and bookmaker odds
- Potential value opportunities

---

# 1. Prediction Process

The model will:

1. Collect historical data
2. Analyse performance factors
3. Calculate probability percentage
4. Convert probability into true odds
5. Compare against available market odds
6. Identify value opportunities
7. Track prediction accuracy

# 5. True Odds Calculation

Formula:

True Odds = 100 ÷ Probability Percentage

Example:

Probability = 25%

True Odds:

100 ÷ 25 = $4.00

If bookmaker odds are higher than $4.00, the model identifies potential value.
